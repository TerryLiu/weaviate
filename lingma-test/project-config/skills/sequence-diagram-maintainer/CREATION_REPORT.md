## 📊 初始时序图内容

已创建 Weaviate 基础数据流时序图,包含:

### 参与者 (9个)
- Client (客户端)
- API (REST API)
- GraphQL (GraphQL API)
- Auth (认证授权)
- Schema (Schema管理)
- Objects (对象管理)
- Vector (向量索引)
- Storage (LSMKV存储)
- Modules (AI模块)

### 主要流程
1. **数据写入流程**: 客户端 → API → 认证 → Schema验证 → AI模块 → 向量索引 → 存储
2. **数据查询流程**: 支持 REST 和 GraphQL 两种查询路径
3. **条件分支**: 展示了缓存命中/未命中的不同处理逻辑

## 💡 使用示例

### 示例 1: 添加新组件

**输入:**
```
在时序图中添加 Raft 共识层:
- Schema管理 -> Raft: 同步Schema变更
- Raft -> 其他节点: 广播变更
- 其他节点 -> Raft: 确认接收
- Raft -> Schema管理: 达成共识
```

**输出:**
自动在时序图中插入 Raft 参与者,并添加相应的交互消息,使用 activate/deactivate 显示活跃状态。

### 示例 2: 细化流程

**输入:**
```
展开 AI模块 的内部流程,展示:
- 文本分词
- 向量生成
- 结果返回
```

**输出:**
将 Modules 参与者展开为详细的子序列,显示内部组件的交互过程。

### 示例 3: 添加错误处理

**输入:**
```
为数据库查询添加错误处理:
- 查询超时返回错误
- 连接失败重试3次
- 重连失败返回服务不可用
```

**输出:**
使用 `alt` 块添加成功和失败的分支流程,清晰展示不同的处理路径。

## 🎨 时序图特性

### 支持的消息类型
- ✅ 同步调用: `->>`
- ✅ 异步消息: `->`
- ✅ 返回消息: `-->>`
- ✅ 自调用: 指向自身

### 支持的控制结构
- ✅ 条件分支: `alt`/`else`/`end`
- ✅ 可选流程: `opt`/`end`
- ✅ 循环处理: `loop`/`end`
- ✅ 并行执行: `par`/`and`/`end`

### 支持的注释和说明
- ✅ 跨参与者注释: `Note over A,B`
- ✅ 单侧注释: `Note right of A`
- ✅ 激活框: `activate`/`deactivate`
